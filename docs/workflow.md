# Browser Flow 流程标准

新通用任务采用 ARTEX 的探索方式：**目标 → 已有事实 → 探索方向 → 单方向执行 → 事实回写 → 重新规划 → 逐项目标证明**。同一 Agent 分阶段承担 Planner 与 Worker，现有六工具和 `/api` 通道承载全部操作。

## 开始任务

用户在面板填写目标、约束所需的允许源站，并自行登录和授权页面；无需预先编写网站导航说明或站点定义。Agent 先读 `browser_observe(view:"task")` 的通用指引；完整指引可用 `ref:"exploration:guide"` 续读。用户原始目标、条件和范围不因 Agent 拆解而删除或降低。

Planner 通过任务 query 读取 `graph_overview`、`list_goals`、`list_facts`、`list_assets`、`asset_neighbors`、`node_detail`。任务查询不授予页面控制；资源与探索节点使用不同引用。列表用返回的 `next_before` 和 `projectionId` 继续读取；任务变化后从头读取。

## 探索与执行

所有语义写入使用 `browser_act(action:"explore", explore:{op,...}, requestId, expectedVersion)`。版本取最新工具返回的 `contextVersion`。相同 ID 仅能重试同一个语义请求；页面操作不重放。

1. `add_intent` 用 summary 描述探索方向，传已有 fact 的 parent_ids、资源 asset_ids；无父事实时挂到起点事实。每批最多四条，priority 为 0–10，默认 5，数值越高越先处理。
2. `claim_intent` 领取一条方向，进入 Worker 阶段。方向可以包含多次观察和操作；一次点击是 attempt，不是探索方向。
3. 按实时观察使用 `browser_find/act/wait`。文档或引用变化后重新读取；歧义不能以取第一项消除。区域及表格观察只说明当前 DOM，不能证明业务全集完整。
4. `record_fact` 回写综合结论，区分 observed/inferred，包含否定结果。资产、页面快照与结论分别记录；新线索交给下一轮 Planner。
5. `finish_intent` 结束方向后重新规划。done 只表示该方向结束；没有待办方向不等于目标完成。

字段映射、菜单、步骤、网站成功含义和新方法均由 Agent 从观察得出，作为有来源的本地事实保存。产品不内置网站业务步骤，不执行 Agent 提供的脚本或流程。

## 文件与目标证明

用户通过原有面板选择、准备并确认文件。新通用任务不填写站点业务身份或固定行范围。`browser_tabs` 返回文件授权和快照引用；`browser_observe(view:"file", ref:<asset>)` 读取中性的工作表/行/单元格，或支持的 JSON/文本。公式不计算，宏和外部链接不执行。`set_file` 仅向当前已授权、可见的文件输入框交付确认的原件快照一次。

Agent 通过 `check_evidence` 提供有界、绑定原始快照的结构化断言，并将检查引用附到 observed fact；Planner 用 `prove_goal(goal_id,evidence_id,reason)` 逐项目标提交业务判断。Host 复核原件、引用和断言，不能独立理解所有网站的业务含义。上传、保存和点击回执均不自动证明最终业务结果。

所有必需目标及条件获证、原件可复验且没有待结算操作、未知写入或人工作业时，Host 记录 completed 并撤销控制和未用文件能力。结论标明 Agent 判断与 Host 证据复核。没有绕过证明直接结束成功的工具。

已有 `coverage` 仍统计可信验证器通过的验收条件；自由文本不会因 Agent 判断而变成代码通过。`assetCoverage` 仅统计当前 run 已知页面/文件资源被事实锚定的情况，不表示全站功能已发现或业务成功。

## 失败与恢复

登录、页面授权、文件选择等实际缺失条件使用原有 `await_user`；用户提供新输入后在面板恢复。恢复本身不授予控制或证明成功。未知写入结果阻断后续写入，跨重启、修订和新 run 保留；只允许安全读取、撤销及交接。

每次显式证据读取重新检查原件。完成后的原件缺失或篡改会显示为不可复核；历史完成记录保留，不自动重新执行业务。面板轮询只显示最后检查的事实，不建立新证明。

## 兼容与交付

旧定义任务保持“固定说明 + 模型逐步编排 + 代码校验”及其既有停止边界，不自动改为新模式。新任务不按域名切回旧适配器。具体站点知识、原件、配置、日志与验收回执均在忽略目录保留；公开交付仅包含通用能力、必要运行产物、说明和合成测试。

技术验收、真实模型自主探索、正常 Desktop Session 接线和真实业务验收分别记录并绑定同一候选。P2/P3 展示、跨任务共享及辅助工具不阻塞本轮 P0/P1 能力。
