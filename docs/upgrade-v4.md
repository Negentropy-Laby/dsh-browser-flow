# Upgrade to Browser Flow v4

Rebuild the plugin and reload matching Host and Client together. Browser Flow is
v4, Go RPC stays v2, kernel is v5 and structural rules stay structural-v1.
The native manifest and projection identity must match the rebuilt helper.
Older peers are rejected; restart derived continuation reads at offset zero.

New generic tasks default to workflowRef exploration and journal generation 2.
A single Agent alternates ARTEX-style planner/worker phases. A semantic intent
contains browser attempts; facts are result nodes, not assets. All required goals
need observed facts and passing source-backed checks. Completion is an Agent
business assessment with Host evidence checks, not an independent code verdict.
Completion withdraws control; later missing originals are shown as unavailable.

Generation-1 tasks retain their bytes, references, original behavior and adapters.
Unversioned/unsupported history remains read-only. No automatic storage migration
or page-action replay occurs. Use a new Session for the generic exploration mode;
old tasks cannot widen their workflow through revise.

The existing six tools carry task queries and action=explore operations. They also
support bounded region/table observations, neutral selected-file views and one-use
file upload. Local definitions and site recipes are unnecessary for new tasks.
Task notes, original files, configuration and receipts remain private and ignored.

See workflow.md and the runtime exploration:guide reference for actual operations.
